使用文档

常用操作速查。找不到入口时，先看这里。

移动与布局不用进编辑态
  • 移动卡片鼠标移到卡片顶部，出现一条短横线后按住拖动。松手自动吸附到 6px 网格和邻卡边缘。
  • 移动面板按住收纳面板的标题栏拖动；右下角斜纹把手可以改面板大小。
  • 键盘选中卡片后按 Shift+F10 或菜单键打开卡片菜单；Esc 关闭菜单和浮层。

卡片操作

  • 右键卡片改尺寸、换材质、添加组件、移除组件都在这里。
  • 单击打开系统监视 / 网络 / 时钟卡片点一下，分别打开任务管理器 / 网络设置 / 时钟。
  • 双击天气双击天气卡打开地区设置，搜索城市或区县后选中即生效。
  • 系统入口点图标打开常用入口；卡片右上「›」展开全部，可搜索、按分类筛选。常用项在「系统入口」页改。

添加与外观

  • 添加组件控制中心 →「添加组件」，或右键卡片 →「添加组件」。按尺寸分组，点哪一档就加哪一档。
  • 材质控制中心一改，所有卡片和面板一起变；右键单卡可临时覆盖，下次改全局会重新统一。
  • 其它设置「外观与行为」里可调缩放、图标标签、时钟秒数，换壁纸后可刷新桌面底图。
桌面收纳真实移动文件
  • 收纳图标把桌面上的图标拖到面板里的分组即可。文件被真实移动到 <桌面>\fy-desktop\<组名>。
  • 分组管理右键分组标题：重命名、上移、下移、在资源管理器中打开、删除。删除分组只会把文件移回桌面。
  • 面板开关「收纳文件夹」页的「桌面收纳」开关只控制面板显不显示，分组和磁盘文件都保留。
托盘与排查出问题先看这里
  • 托盘左键托盘图标打开控制中心；右键还有开机自启、显示秒、打开收纳目录、配置文件、关于和退出。
  • 配置与日志都在 %APPDATA%\com.fy.desktop：config.json 是配置，launch.log 记录每次打开动作。
  • 打开失败系统入口点了没反应时，看 launch.log 里的 ShellExecute 错误码，桌面也会弹一条提示。
  • 图标被挡卡片默认从左侧空出一段给桌面图标。图标太多时把图标收进分组，或直接拖动卡片避开。

收纳文件夹

每个分组就是磁盘上的真实文件夹；改名会同步改目录名，删分组会把内容移回桌面。

根目录 — 分组 0 已收纳 0 项 桌面收纳
删除分组只会把里面的项目移回桌面，不会删除任何文件。
