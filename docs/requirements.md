# fy-desktop 需求文档

> 版本：v0.9.2 ｜ 最后更新：2026-11-16 ｜ 状态：已实现

## 1. 背景

Windows 桌面长期存在两个割裂的问题：

1. **信息要一层层点开才知道**。时间、天气、CPU、网速这些每天看几十次的信息，散落在任务栏托盘和各个应用里，没有一处「抬眼就能看到」的位置。
2. **图标越堆越多**。快捷方式、临时文件、下载的东西默认全落在桌面，最后桌面变成一片图标海，找东西靠肉眼扫描。

市面上 Fences 一类工具解决了收纳，但不做信息展示；Rainmeter 一类工具能展示，但配置成本高、视觉老旧。参考项目 [atrium-desktop](https://github.com/wynter-yaxley/atrium-desktop) 提供了方向：**液态玻璃质感的桌面层**，但它同时带了一整套任务栏 / 控制中心，超出本项目需要。

`fy-desktop` 只做两件事：**桌面小组件** + **桌面快捷方式收纳格子**。

## 2. 目标与非目标

### 2.1 目标

| 编号 | 目标                    | 衡量方式                                         |
| -- | --------------------- | -------------------------------------------- |
| G1 | 抬眼可见：常用信息常驻桌面         | 7 个组件可任意增减，其中网络组件为必需项                        |
| G2 | 桌面变干净：快捷方式按组收进格子      | 收纳是**真实移动**到 `<桌面>\fy-desktop\<组名>`，可移回      |
| G3 | 不打扰：不抢焦点、不挡桌面图标、不上任务栏 | 空区域鼠标穿透；`SW_SHOWNOACTIVATE` 显示；`skipTaskbar` |
| G4 | 可反悔：移动不丢文件、不覆盖        | 重名自动 `(2)`；移出即还原位置                           |
| G5 | 视觉统一：一套玻璃语言贯穿所有组件     | 设计令牌集中管理；玻璃来自真实壁纸模糊                          |
| G6 | 装完就用：一个安装包 + 开机自启     | NSIS 单文件安装包，per-user，无需管理员                   |

### 2.2 非目标（明确不做）

- ❌ **不做任务栏 / Dock**。参考项目的悬浮 Dock 属于独立模块，本项目不实现。
- ❌ **不做启动器 / 搜索**。不做全局搜索、应用启动、快捷指令。
- ❌ **不做窗口管理**（贴边、分屏、虚拟桌面）。
- ❌ **不做账号体系与云同步**。所有数据留在本机。
- ❌ **不做壁纸管理**。只使用系统壁纸，不接管、不修改。
- ❌ **不删除用户文件**。收纳只移动，且可移回；删除能力不提供。
- ❌ **不做静默替换式自动更新**。检查更新、提示、一键安装可以做
  （FR-21，v0.8 已实现），但程序绝不趁用户不注意自己换掉自己的 exe。

## 3. 目标用户与场景

**主用户**：Windows 10/11 上长时间面对电脑的重度用户——开发者、设计师、运营。特征是多窗口并行、桌面文件多、对视觉有要求。

**典型场景**

| 场景      | 触发            | 期望                         |
| ------- | ------------- | -------------------------- |
| 抬眼查信息   | 工作时随意一瞥       | 不用切窗口就知道几点、什么天气、机器热不热、网卡不卡 |
| 桌面被塞满   | 装完一堆软件、收了一堆文件 | 一键把散的图标收进格子，需要时从格子点开       |
| 换壁纸想换观感 | 换了深色壁纸        | 玻璃自动翻成深玻璃+浅字；也能给单张卡选暮色/石墨 |
| 组件不合用   | 不需要日历，想要数字时钟  | 移除一个、添加一个，拖到合适位置，拉角改大小     |
| 重装系统    | 换了台机器         | 双击安装包，登录即自动出现              |

## 4. 功能需求

优先级：P0 = 必须；P1 = 应该有；P2 = 可以有。

### FR-01 桌面小组件（P0）

| 组件   | 默认尺寸（设计像素） | 内容                                     | 数据来源                                              | 刷新    |
| ---- | ---------- | -------------------------------------- | ------------------------------------------------- | ----- |
| 天气   | 210×102    | 地点（可到区县）、当前温度、天气现象、最高/最低、未来 6 小时（可跨天）  | Open-Meteo → wttr.in 回退；地名走 photon                | 15 分钟 |
| 模拟时钟 | 210×102    | 表盘、刻钟刻度、12 数字、时分秒针                     | 本地时间                                              | 1 秒   |
| 数字时钟 | 102×102    | 大字号时间 + 日期                             | 本地时间                                              | 1 秒   |
| 日历   | 210×102    | 今日大字、年月周、当月网格、今日高亮                     | 本地时间                                              | 60 秒  |
| 系统监视 | 210×102    | CPU / 内存 / 磁盘占用条 + CPU 走势 + 运行时长 + 核心数 | `sysinfo`                                         | 1 秒   |
| 网络   | 210×102    | 上下行速率、延迟、链路类型/SSID、信号、**出口网卡 IP**、吞吐走势 | `sysinfo` 网卡差分 + TCP 握手 + `netsh wlan` + UDP 路由探测 | 1 秒   |
| 备忘录  | 210×102    | 两行随记，自动保存                              | 本机配置                                              | 输入即存  |

默认尺寸就是该组件的默认档位（FR-17）：数字时钟默认小号 102×102，其余默认中号
210×102；换档后按小 102×102 / 中 210×102 / 大 210×126 取值。

### FR-02 网络组件（P0）

- 速率 = 累计字节差分 / 采样间隔，再走 EMA(0.45) 平滑，避免数字乱跳。
- 延迟 = 对 `223.5.5.5:443` 做 TCP 握手计时（不用 ICMP，免提权）。
- 链路类型与 SSID 来自 `netsh wlan show interfaces` 解析，12 秒缓存。
- 无线显示信号格，有线隐藏信号并标注「有线」。
- 采样失败时保留上一帧并标灰，不显示 `NaN`。
- 吞吐走势占卡片右侧 2/3，高度随卡片走；量程自适应，不用写死的上限（v0.5）。

### FR-03 组件增删与尺寸（P0，v0.2 新增，v0.6/v0.7 改）

v0.7 起所有操作都从**卡片右键菜单**进（见 FR-18），编辑态只剩「拖动」。

| 能力  | 交互                            | 约束                          |
| --- | ----------------------------- | --------------------------- |
| 添加  | 卡片右键「添加组件…」或托盘「添加组件…」         | 组件库按尺寸分组，点哪一档就按哪一档加；自动找空位   |
| 移除  | 卡片右键「移除组件」                    | 至少保留一个组件                    |
| 移动  | 卡片右键「调整布局…」→ 拖卡片              | 松手即写配置，320ms 防抖落盘；Esc 退出编辑态 |
| 尺寸  | 卡片右键 → 小 / 中 / 大（按该组件支持的档位列出） | 只有三档预设，见 FR-17；当前档打勾并禁用     |
| 材质  | 组件库材质按钮（全局统一）或卡片右键「材质」（单卡覆盖） | 改全局时所有元素一起变，见 FR-24；缺字段＝跟随全局 |
| 持久化 | 自动                            | 位置尺寸写 `config.json`，重启保持    |

### FR-17 预设尺寸（P0，v0.6 新增）

尺寸从「连续自由度」改成「离散集合」，这是能对齐的前提。

- 三档固定尺寸（设计像素）：小 `102×102`、中 `210×102`、大 `210×126`；中/大同宽。
- 中/大宽度 = 两个小 + 一条最小缝：`2×102+6=210`，两张小卡并排正好顶一张中卡。
- 宽高都取吸附网格 6 的整数倍，邻卡之间固定留 6，缝隙因此只可能是 6 或它的整数倍。
- 所有组件共用同一套档位，所以任意两张同档卡片宽高完全一致。
- 小号必须**删内容**而不是缩字号：
  - 天气：只显示今天的气温 / 天气 / 高低温，逐时预报收起；
  - 时钟（模拟）：收起表盘，只留数字时间 + 日期；
  - 网络：只留上下行速率，走势图、延迟 / IP、在线点都收起；
  - 系统监视：只留 CPU / 内存 / 磁盘 三个百分比，进度条与走势图收起。
- **「大」只留给备忘录**（v0.7）：天气 / 模拟时钟 / 数字时钟 / 日历 / 系统监视 /  
  网络 一律只有小、中两档。多出来的 60px 高度只够把同样的内容排松一点，  
  在桌面上却是实打实多占一块地方。
- 日历与备忘录不支持小号（整月网格、输入区塞不进 102×102）；日历因此只剩「中」。
- 档位允许集合在后端 `config::sizes_for()` 与前端 `REGISTRY[kind].sizes` 各写一份，  
  必须保持一致。
- 旧配置迁移：已取消的档位按**档位距离**归位（`l → m`），再只沿 y 让位消除重叠  
  （不拆横排）。不能按宽高比算——210×126 的 1.67 反而更接近 1:1 的「小」。

### FR-04 桌面快捷方式收纳（P0）

- 收纳根目录默认 `<桌面>\fy-desktop`，可在配置里改。
- **每个分组 = 一个真实文件夹** `<收纳根>\<组名>`。用资源管理器直接操作同样有效。
- 扫描范围：当前用户桌面 + 公共桌面；排除 `desktop.ini`、隐藏文件、收纳根本身。
- 分组：开发工具 / 设计素材 / 常用文档 / 影音图像 / 归档 / 待整理；名称关键词自动归类。
- 面板内显示每个分组的条目网格：**7 列、正方形格子**，超出 7 个自动换行；
  条目不足一行补齐，保持网格对齐。格子边长随面板宽度等比变化（面板宽度可拖右下圆点调）。
- 格子里标签只占一行，名字长了直接省略号（全名走 `title` 悬停），图标 24px。
- 面板右上角有「全部折叠 / 展开」按钮：一次收起或展开全部真实分组；「待整理」是
  虚拟分组，始终展开，不参与这次折叠。
- 空分组显示一行提示文案，不显示空网格。
- 面板可开关：`organizer.enabled` 控制面板在桌面上显示与否。两个入口共用同一个开关
  状态——面板右键菜单最后一项「移除桌面收纳」，以及控制中心「分组」页信息条里的
  「桌面收纳」开关（走 `hub_action: set-organizer`，由桌面窗口执行并落盘）。
  关掉只是不显示，分组、格子里的文件、根目录设置全部保留；重开后沿用原来的位置与尺寸。
  面板隐藏期间不参与热区、吸附参考线与拖放命中。

### FR-05 移入 / 移回（P0）

- 移入：拖拽桌面图标到分组 → `move_into`；同盘 `rename`，跨盘复制后删源。
- 移回：右键 →「移出收纳」→ 放回桌面；若桌面已有同名文件，加 `(2)`。
- **重名绝不覆盖**：目标已存在则生成 `name (2).ext`、`name (3).ext`。
- 一键整理：先出预览（哪些文件 → 哪个组），确认后执行。
- 删除分组：先把组内文件搬回桌面，再删空目录（不允许连带删文件）。

### FR-06 真实图标（P1，v0.2 新增）

- 通过 `IShellItemImageFactory::GetImage`（`SIIGBF_ICONONLY`）取 64×64 位图。
- `.lnk`、文件夹、文档、图片均显示系统给的真实图标，不再用首字色块。
- 缓存键 = `SHA256(路径 + mtime + size)`，命中不碰 COM；图标失效自动重取。
- 取不到图标时降级为类型色块 + 扩展名，不阻塞渲染。

### FR-07 真毛玻璃与自适应明暗（P1，v0.2 新增）

- 玻璃底图必须是**真实壁纸**的模糊，不是纯色半透明。
- 启动与换壁纸后重新抓图；抓图时把自己从截图中排除（`WDA_EXCLUDEFROMCAPTURE`）。
- 底图整屏平均亮度低于阈值时，全部卡片统一切深玻璃 + 浅字，保证可读性。
- 底图获取失败时降级为纯色玻璃，界面不得空白。

### FR-08 窗口行为（P0）

- 无边框、透明、不进任务栏、不进 Alt+Tab、常驻桌面底层（`alwaysOnBottom`）。
- 空白区域鼠标穿透：桌面图标可点、右键菜单可用、可框选。
- 显示不抢焦点（`SW_SHOWNOACTIVATE`）。
- 按 Win+D / 显示桌面 被最小化后自动回到桌面层。
- 关窗口 = 隐藏，不退出；退出走托盘。

### FR-09 托盘与开机自启（P0，v0.2 新增）

- 托盘菜单：控制中心 / 开机自启（勾选）/ 时钟显示秒（勾选）/ 打开收纳文件夹 / 设置文件… / 退出。添加组件、刷新桌面底图、天气地区、关于都在控制中心里，不再单列。
- 菜单打开后点任何地方都要收回（桌面、其它应用、任务栏都算）：
  前端判 `.tm` 菜单盒，点其它应用时我们窗口收不到事件，由后端 30ms 轮询 +
  `GetAsyncKeyState(VK_LBUTTON)` 兜底。
- v0.7 起托盘不再有「编辑布局」：它和「添加组件」挨在一起时分不清，而且进了编辑态  
  还是得回卡片上操作。布局入口统一在卡片右键菜单（FR-18）。
- 开机自启默认开启（安装版首启登记）。
- 自启项只写 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，**不写 HKLM**。
- 勾选状态读系统注册表真实值，不以配置为准。

### FR-10 安装包（P0，v0.2 新增）

- NSIS 单文件安装包，体积 < 5 MB。
- per-user 安装到 `%LOCALAPPDATA%\fy-desktop`，**不需要管理员权限**。
- 创建开始菜单与桌面快捷方式；注册卸载项（设置 → 应用 可见）。
- 支持 `/S` 静默安装与静默卸载。
- 卸载不删用户配置与收纳文件。

### FR-11 布局对齐（P1，v0.4 新增）

- 拖动与拉角时坐标落到 8 设计像素网格，不出现 1–3px 的歪斜。
- 6px 内吸附到其它卡片与收纳面板的参考线：横向左/中/右，纵向上/中/下。
- 吸附命中时显示橙色参考线，松手消失。
- 目标：不同组件能落在同一条线上，也能拉成一致的宽高。

### FR-12 分组管理（P1，v0.4 新增）

- 分组标题上右键：重命名 / 上移 / 下移 / 在资源管理器中打开 / 删除。
- 面板空白处或标题栏右键：与组件右键**同一套结构**（标题 → 材质 → 动作），
  即 `桌面收纳 · N 组 · M 项` / 玻璃·暮色·石墨 / 全部折叠·展开 / 新建分组 /
  在资源管理器中打开 / 刷新；面板没有尺寸档位，所以不出「尺寸」「调整布局」。
- 重命名会同步重命名磁盘目录；顺序调整只改配置顺序，不动文件。
- 删除分组前必须把组内文件移回桌面，不允许连带删文件。

### FR-13 天气地点（P1，v0.4 新增）

- 天气卡双击，或托盘「天气地区…」打开搜索弹层。
- 支持中文省 / 市 / 区县（如「西湖区」「阳新县」），选中即生效并立即重拉。
- 卡片标题显示末级地名，悬停显示完整「省 · 市 · 区」。
- 搜索失败或离线时给出可读提示，不改变当前地点。

### FR-14 逐时预报跨天（P1，v0.5 新增）

- 「未来 6 小时」必须真的是接下来 6 个整点，不受当天剩余小时数限制。
- 跨到明天的格子有可见标记（标签上方小圆点），悬停提示「明天 08时」。
- 取数用接口返回的 `current.time` 对齐，不拿本机钟去猜时区。

### FR-15 打开收纳目录（P0，v0.5 新增）

- 面板右上角按钮与托盘菜单都要能打开收纳根目录。
- 必须走 `ShellExecuteW`：经由 `cmd /c start` 启动时，无控制台进程会派生出隐藏窗口。
- 失败不能静默：写 `launch.log`（含错误码），前端 toast 提示。

### FR-18 组件右键菜单（P0，v0.7 新增）

右键任意卡片即得到这张卡的全部设置，不必先进入编辑态：

| 项         | 行为                           |
| --------- | ---------------------------- |
| 标题行       | `组件名 · 当前档 宽×高`，只读           |
| 小 / 中 / 大 | 只列该组件支持的档位，当前档打勾并禁用；点其它档立即切换 |
| 调整布局…     | 进入编辑态（虚线框 + 可拖动），Esc 或「完成」退出 |
| 添加组件…     | 打开组件库                        |
| 移除组件      | 只剩一个组件时禁用                    |

- 菜单配色跟随当前材质（玻璃浅色 / 暮色与石墨深色），深色壁纸下不弹白板。
- 编辑态不再有卡片工具条与拉角把手；收纳面板右下角的把手保留。

### FR-19 组件库按尺寸分组（P1，v0.7 新增；v1.1 起并入控制中心）

- 组件库分「小 / 中 / 大」三段，每段只列支持该档的组件，标题写明尺寸与一句话说明。
- 每项带一枚预览迷你卡，比例等于该档的真实比例（102×102 / 210×102 / 210×126），  
  配色取自当前材质。
- 点哪一项就按哪一档添加；不在该档的组件不出现（例如日历只出现在「中」）。
- 窗口底色、文字色、材质按钮配色与当前材质一致，材质按钮本身就是对应色块。

### FR-20 应用图标（P1，v0.7 新增）

- 图标需包含 `fy` 两个字母，圆角方形深色玻璃底，与「石墨」材质同族配色。
- 源文件 `assets/icon.svg`；`npm run icon` 一次生成 ico / png / icns 全套。
- 安装程序（`installerIcon`）、开始菜单、桌面快捷方式、任务栏、托盘使用同一枚图标。
- 32×32 下仍能辨认 `fy`。

### FR-21 关于页与检查更新（P1，v0.8 新增；v1.1 起并入控制中心）

- 托盘新增「关于 fy-desktop…」，面板内含：名称 + 版本号、更新源链接、
  「检查更新」按钮、「自动更新」开关。
- 更新源是 GitHub Releases（仓库 `fsdymy1024/fy-desktop`）：读最新 release，
  从 assets 里挑带 `setup` 的 exe 拿直链。
- 「自动更新」= 启动约 10 秒后后台查一次，发现新版本只弹一条 toast
  （不打断、不抢焦点）；可在关于页关掉，开关持久化到配置。
- 「下载并安装」：下载安装包到临时目录 → `/S` 静默安装 → 应用退出重启。
  **不做静默替换**（程序自己换自己的 exe 风险不可控）。
- 仓库未建 / 无 release / 断网时，检查结果照实显示原因，不得假装「已是最新」。

### FR-22 代码签名（P1，v0.8 新增）

- 主程序 exe 与 NSIS 安装包带 Authenticode 签名 + RFC3161 时间戳。
- 签名器是 `src-tauri/scripts/sign.ps1`（挂在 `signCommand`）；证书指纹按
  `FY_SIGN_THUMBPRINT` → `scripts/sign.env.json` 读取，都没有则**跳过签名**继续出包。
- 当前为本机自签证书（`make-cert.ps1` 生成，3 年有效期）：签名真实可校验，
  证书链不在受信任根，Windows 仍显示「未知发布者」；换正式证书只改指纹。

### FR-23 快捷方式图标即装即新（P1，v0.8 新增）

- 安装时把 `fy-desktop.ico` 装进 `%LOCALAPPDATA%\fy-desktop\`。
- NSIS `POSTINSTALL` 钩子重建桌面 / 开始菜单快捷方式，`IconLocation` 显式指向该 ico，
  并执行 `ie4uinit.exe -show` 刷新 shell 图标缓存。
- 动机：资源管理器图标缓存按 exe 路径记，重装换图标后快捷方式会一直显示旧图。

### FR-24 材质：全局统一应用（P1，v0.9 新增，v0.9.1 修订）

两轮反馈合起来的结论是：**改材质时所有元素一起变**，包括各个组件、
「添加组件」页、「关于 fy-desktop」页、「设置天气地区」页。v0.9.0 曾把材质
拆成「每卡一份、组件库只给新卡」，属过度解读；v0.9.1 定稿为全局统一 +
单卡可事后覆盖。

- 唯一变更入口 `setGlobalMaterial(mat)`：写全局 `cfg.material` → 清空所有
  单卡材质覆盖 → 逐张刷新卡片 `data-material` → 同步组件库选中态 → 重判抓屏。
- 卡片默认跟随全局（`WidgetCfg.material` 空串 / 缺字段＝跟随，老配置免迁移）；
  卡片右键「材质」分组（玻璃 / 暮色 / 石墨，当前项打勾）可单独覆盖，
  下一次改全局会重新统一。
- 收纳面板与全部浮层的配色由 `body[data-material]` 的 `--pop-*` 提供；
  组件库另有一套 `--gal-*`（按 `.gal[data-mat]` 取值），必须显式同步，
  不能只靠变量继承。
- 玻璃回 v0.7.0 配色：白膜 `--veil` 0.80、`--fill` 0.86；恢复整屏亮度采样
  的明暗自适应，但**只对玻璃卡生效**，暮色 / 石墨不被亮度改写。
- 保留 v0.8 的叠层修复：白膜画在 `::before` 的 `background-image` 第一层。
- 抓屏判断按「是否存在需要底图的卡片」，不能只看全局材质是不是石墨。

### FR-25 浮层窗口交互（P1，v0.9.1 新增；v1.1 起由 FR-27 控制中心替代）

- 组件库 / 关于页 / 天气地区弹窗都能**拖标题栏移动**；位置按窗口记在
  `localStorage`，关掉再开保持在原处；偏移受限，窗口不会整块飞出视口。
- **点窗口以外的桌面即关闭**：浮层打开时整窗接管鼠标，遮罩必须吃掉这一下，
  否则桌面被一块透明板锁死（v0.9.8 从「点外部不关」改回）。
  只有「按下的位置就是遮罩」才算，从面板里拖到遮罩上松手不关。
- 右上角 `x`、Esc、弹窗「取消」同样关闭；三个窗口都有 `x`，
  天气地区弹窗补齐这一枚按钮。
- 标题栏里的材质按钮、关闭按钮、输入框不触发拖动，点击行为照常。

### FR-26 截图可见性（P1，v0.9.2 新增）

毛玻璃底图要求「抓一张不含自己的桌面」，v0.1 用 `WDA_EXCLUDEFROMCAPTURE`
实现，但**常开**了——这个标志是对所有截图工具隐形的系统级开关，副作用是
用户用 Windows 截图工具 / PrintScreen / 第三方截图时组件全部消失。

- 窗口默认 `WDA_NONE`：任何截图工具都能拍到组件（正常桌面元素身份）。
- 仅在抓玻璃底图的瞬间（`snapshot(hwnd, false)` / 底图路径的 `raw_png`）
  临时设排除，抓完立刻还原，全程 ~150ms；设排除后留 150ms 等 DWM 合成一帧。
- `include_window = true` 的自检截图不做任何切换。
- 自家组件（时钟 / 右键菜单 / 浮层）不在此列，本来就该被拍到。

### FR-27 控制中心（P0，v1.1 新增）

v1.1 之前，组件库 / 关于 / 天气地区 / 分组命名都是叠在桌面层上的浮层：打开时整窗接管鼠标，
桌面被一块透明板压住，误关与漏关都出过问题。v1.1 把它们收进一个**独立的普通窗口**。

- 窗口 `label = hub`，在 `tauri.conf.json` 里声明、启动时以 `visible: false` 建好，
  运行时只 `show` / `hide`。不在运行时新建第二套 WebView2（同机实测会拿到不绘制的空白窗口）。
- 托盘**左键**打开 / 收起控制中心（已在前台时再点收起），**右键**仍是快捷菜单。
- 五个页面：我的组件 / 添加组件 / 设置 / 分组 / 关于。
- 「添加组件 / 换尺寸 / 换材质 / 换缩放」不直接改配置：控制中心发 `hub_action`，
  由桌面窗口执行找空位、吸附、热区与落盘，布局算法只有一份，两边不会漂移。
- 窗口尺寸按屏宽自适应：`ui = clamp(屏宽 / 2880, 1, 1.5)`——4K 上 1200×825、
  1080p 上 1:1（900×620）。位置记在 `localStorage`，拖到哪儿下次开在哪儿。
- 桌面侧触发的「天气地区 / 新建分组 / 重命名分组」带 `compact` 意图：**只显示弹窗本身**，
  主界面隐藏、窗口尺寸与初始位置不动（弹窗可拖标题行移动），关掉弹窗窗口一起隐藏。
- 后端配置一变就广播 `config:changed`；控制中心开着时，桌面上的右键操作会实时反映到列表。
- 冷启动竞态：页面在窗口隐藏期间被 WebView2 挂起，首次 `hub_boot` 往往早于意图到达，
  监听注册后必须再补取一次后端攒下的 `pending`，否则「点桌面上的天气地区」毫无反应。
- 启动竞态：桌面层的 `boot` 若早于后端 `app.manage(AppState)`，会以
  `state not managed` 失败并整层放弃渲染；启动命令对这类错误自动重试，其它错误照常抛出。

## 5. 非功能需求

| 类别  | 要求                                                            |
| --- | ------------------------------------------------------------- |
| 性能  | 常驻 CPU < 1%（采样 1 秒一次、光标轮询 30ms 只做 `GetCursorPos`）；内存 < 150 MB |
| 首屏  | 冷启动到可见 < 2 秒（不含抓屏，抓屏异步补）                                      |
| 缩放  | 设计坐标系 1920×1080，`ui = (屏宽/1920).clamp(1,2)`，4K 屏 2.0          |
| 可靠性 | 文件移动原子性：同盘 rename；跨盘复制成功后再删源，中间失败保留源                          |
| 隐私  | 无账号、无遥测；唯一外网请求是天气（只带经纬度）                                      |
| 可维护 | Rust 侧零 `unwrap` 崩溃点；无界面自检覆盖 8 项核心链路                          |
| 可诊断 | 截图自检可导出窗口/缩放/卡片矩形 JSON；事件监听失败会在页面上直接报错                        |

## 6. 交互约束

1. **不夺焦**：任何时候不得抢走前台窗口焦点，包括启动、截图、托盘操作。
2. **不挡手**：卡片之外的区域对鼠标完全透明，包括右键与框选。
3. **不惊喜**：任何会移动用户文件的操作，必须先给预览或二次确认。
4. **不覆盖**：任何写文件路径都必须先做重名检测。
5. **可反悔**：移动过的文件都能移回原位。
