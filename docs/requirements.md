# fy-desktop 需求文档

> 版本：v0.2.0 ｜ 最后更新：2026-11-15 ｜ 状态：已实现

## 1. 背景

Windows 桌面长期存在两个割裂的问题：

1. **信息要一层层点开才知道**。时间、天气、CPU、网速这些每天看几十次的信息，散落在任务栏托盘和各个应用里，没有一处「抬眼就能看到」的位置。
2. **图标越堆越多**。快捷方式、临时文件、下载的东西默认全落在桌面，最后桌面变成一片图标海，找东西靠肉眼扫描。

市面上 Fences 一类工具解决了收纳，但不做信息展示；Rainmeter 一类工具能展示，但配置成本高、视觉老旧。参考项目 [atrium-desktop](https://github.com/wynter-yaxley/atrium-desktop) 提供了方向：**液态玻璃质感的桌面层**，但它同时带了一整套任务栏 / 控制中心，超出本项目需要。

`fy-desktop` 只做两件事：**桌面小组件** + **桌面快捷方式收纳格子**。

## 2. 目标与非目标

### 2.1 目标

| 编号 | 目标                    | 衡量方式                                         |
| -- | --------------------- | -------------------------------------------- |
| G1 | 抬眼可见：常用信息常驻桌面         | 7 个组件可任意增减，其中网络组件为必需项                        |
| G2 | 桌面变干净：快捷方式按组收进格子      | 收纳是**真实移动**到 `<桌面>\fy-desktop\<组名>`，可移回      |
| G3 | 不打扰：不抢焦点、不挡桌面图标、不上任务栏 | 空区域鼠标穿透；`SW_SHOWNOACTIVATE` 显示；`skipTaskbar` |
| G4 | 可反悔：移动不丢文件、不覆盖        | 重名自动 `(2)`；移出即还原位置                           |
| G5 | 视觉统一：一套玻璃语言贯穿所有组件     | 设计令牌集中管理；玻璃来自真实壁纸模糊                          |
| G6 | 装完就用：一个安装包 + 开机自启     | NSIS 单文件安装包，per-user，无需管理员                   |

### 2.2 非目标（明确不做）

- ❌ **不做任务栏 / Dock**。参考项目的悬浮 Dock 属于独立模块，本项目不实现。
- ❌ **不做启动器 / 搜索**。不做全局搜索、应用启动、快捷指令。
- ❌ **不做窗口管理**（贴边、分屏、虚拟桌面）。
- ❌ **不做账号体系与云同步**。所有数据留在本机。
- ❌ **不做壁纸管理**。只使用系统壁纸，不接管、不修改。
- ❌ **不删除用户文件**。收纳只移动，且可移回；删除能力不提供。
- ❌ **不做自动更新**。v0.2 阶段用安装包覆盖升级，配置与收纳文件不受影响。

## 3. 目标用户与场景

**主用户**：Windows 10/11 上长时间面对电脑的重度用户——开发者、设计师、运营。特征是多窗口并行、桌面文件多、对视觉有要求。

**典型场景**

| 场景      | 触发            | 期望                         |
| ------- | ------------- | -------------------------- |
| 抬眼查信息   | 工作时随意一瞥       | 不用切窗口就知道几点、什么天气、机器热不热、网卡不卡 |
| 桌面被塞满   | 装完一堆软件、收了一堆文件 | 一键把散的图标收进格子，需要时从格子点开       |
| 换壁纸想换观感 | 换了深色壁纸        | 玻璃自动跟随壁纸，深色壁纸自动切浅字         |
| 组件不合用   | 不需要日历，想要数字时钟  | 移除一个、添加一个，拖到合适位置，拉角改大小     |
| 重装系统    | 换了台机器         | 双击安装包，登录即自动出现              |

## 4. 功能需求

优先级：P0 = 必须；P1 = 应该有；P2 = 可以有。

### FR-01 桌面小组件（P0）

| 组件   | 默认尺寸（设计像素） | 内容                                     | 数据来源                                              | 刷新    |
| ---- | ---------- | -------------------------------------- | ------------------------------------------------- | ----- |
| 天气   | 296×128    | 地点（可到区县）、当前温度、天气现象、最高/最低、未来 6 小时（可跨天）  | Open-Meteo → wttr.in 回退；地名走 photon                | 15 分钟 |
| 模拟时钟 | 296×200    | 表盘、刻钟刻度、12 数字、时分秒针                     | 本地时间                                              | 1 秒   |
| 数字时钟 | 208×90     | 大字号时间 + 日期                             | 本地时间                                              | 1 秒   |
| 日历   | 296×150    | 今日大字、年月周、当月网格、今日高亮                     | 本地时间                                              | 60 秒  |
| 系统监视 | 296×150    | CPU / 内存 / 磁盘占用条 + CPU 走势 + 运行时长 + 核心数 | `sysinfo`                                         | 1 秒   |
| 网络   | 296×138    | 上下行速率、延迟、链路类型/SSID、信号、**出口网卡 IP**、吞吐走势 | `sysinfo` 网卡差分 + TCP 握手 + `netsh wlan` + UDP 路由探测 | 1 秒   |
| 备忘录  | 296×116    | 两行随记，自动保存                              | 本机配置                                              | 输入即存  |

### FR-02 网络组件（P0）

- 速率 = 累计字节差分 / 采样间隔，再走 EMA(0.45) 平滑，避免数字乱跳。
- 延迟 = 对 `223.5.5.5:443` 做 TCP 握手计时（不用 ICMP，免提权）。
- 链路类型与 SSID 来自 `netsh wlan show interfaces` 解析，12 秒缓存。
- 无线显示信号格，有线隐藏信号并标注「有线」。
- 采样失败时保留上一帧并标灰，不显示 `NaN`。
- 吞吐走势占卡片右侧 2/3，高度随卡片走；量程自适应，不用写死的上限（v0.5）。

### FR-03 组件增删与尺寸（P0，v0.2 新增，v0.6 改）

| 能力  | 交互                    | 约束                       |
| --- | --------------------- | ------------------------ |
| 添加  | 托盘「添加组件…」→ 组件库 → 添加   | 自动寻找不与现有卡片重叠的空位          |
| 移除  | 编辑态卡片右上 ×            | 至少保留一个组件                 |
| 移动  | 编辑态拖卡片                | 松手即写配置，320ms 防抖落盘        |
| 尺寸  | 编辑态卡片右上角 小 / 中 / 大（v0.6 起不再拖角缩放） | 只有三档预设，见 FR-17；日历与备忘录没有小号 |
| 持久化 | 自动                    | 位置尺寸写 `config.json`，重启保持 |

### FR-17 预设尺寸（P0，v0.6 新增）

尺寸从「连续自由度」改成「离散集合」，这是能对齐的前提。

- 基准边长 `a = 120` 设计像素；三档：小 `a×a`、中 `2a×a`、大 `2a×1.5a`。
- 所有组件共用同一套档位，所以任意两张同档卡片宽高完全一致。
- 小号必须**删内容**而不是缩字号：
  - 天气：只显示今天的气温 / 天气 / 高低温，逐时逐报收起；
  - 时钟（模拟）：收起表盘，只留数字时间 + 日期；
  - 网络：只留上下行速率，走势图、延迟 / IP、在线点都收起；
  - 系统监视：只留 CPU / 内存 / 磁盘 三个百分比，进度条与走势图收起。
- 日历与备忘录不支持小号（整月网格、输入区塞不进 120×120）。
- 旧配置迁移：按宽高比归到最接近的档位，再只沿 y 让位消除重叠（不拆横排）。

### FR-04 桌面快捷方式收纳（P0）

- 收纳根目录默认 `<桌面>\fy-desktop`，可在配置里改。
- **每个分组 = 一个真实文件夹** `<收纳根>\<组名>`。用资源管理器直接操作同样有效。
- 扫描范围：当前用户桌面 + 公共桌面；排除 `desktop.ini`、隐藏文件、收纳根本身。
- 分组：开发工具 / 设计素材 / 常用文档 / 影音图像 / 归档 / 待整理；名称关键词自动归类。
- 面板内显示每个分组的条目网格，超出 8 列自动换行；条目不足一行补齐，保持网格对齐。
- 空分组显示一行提示文案，不显示空网格。

### FR-05 移入 / 移回（P0）

- 移入：拖拽桌面图标到分组 → `move_into`；同盘 `rename`，跨盘复制后删源。
- 移回：右键 →「移出收纳」→ 放回桌面；若桌面已有同名文件，加 `(2)`。
- **重名绝不覆盖**：目标已存在则生成 `name (2).ext`、`name (3).ext`。
- 一键整理：先出预览（哪些文件 → 哪个组），确认后执行。
- 删除分组：先把组内文件搬回桌面，再删空目录（不允许连带删文件）。

### FR-06 真实图标（P1，v0.2 新增）

- 通过 `IShellItemImageFactory::GetImage`（`SIIGBF_ICONONLY`）取 64×64 位图。
- `.lnk`、文件夹、文档、图片均显示系统给的真实图标，不再用首字色块。
- 缓存键 = `SHA256(路径 + mtime + size)`，命中不碰 COM；图标失效自动重取。
- 取不到图标时降级为类型色块 + 扩展名，不阻塞渲染。

### FR-07 真毛玻璃与自适应明暗（P1，v0.2 新增）

- 玻璃底图必须是**真实壁纸**的模糊，不是纯色半透明。
- 启动与换壁纸后重新抓图；抓图时把自己从截图中排除（`WDA_EXCLUDEFROMCAPTURE`）。
- 底图整屏平均亮度低于阈值时，全部卡片统一切深玻璃 + 浅字，保证可读性。
- 底图获取失败时降级为纯色玻璃，界面不得空白。

### FR-08 窗口行为（P0）

- 无边框、透明、不进任务栏、不进 Alt+Tab、常驻桌面底层（`alwaysOnBottom`）。
- 空白区域鼠标穿透：桌面图标可点、右键菜单可用、可框选。
- 显示不抢焦点（`SW_SHOWNOACTIVATE`）。
- 按 Win+D / 显示桌面 被最小化后自动回到桌面层。
- 关窗口 = 隐藏，不退出；退出走托盘。

### FR-09 托盘与开机自启（P0，v0.2 新增）

- 托盘菜单：添加组件… / 编辑布局 / 刷新桌面底图 / 天气地区… / 开机自启（勾选）/ 打开收纳文件夹 / 设置文件… / 退出。
- 开机自启默认开启（安装版首启登记）。
- 自启项只写 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，**不写 HKLM**。
- 勾选状态读系统注册表真实值，不以配置为准。

### FR-10 安装包（P0，v0.2 新增）

- NSIS 单文件安装包，体积 < 5 MB。
- per-user 安装到 `%LOCALAPPDATA%\fy-desktop`，**不需要管理员权限**。
- 创建开始菜单与桌面快捷方式；注册卸载项（设置 → 应用 可见）。
- 支持 `/S` 静默安装与静默卸载。
- 卸载不删用户配置与收纳文件。

### FR-11 布局对齐（P1，v0.4 新增）

- 拖动与拉角时坐标落到 8 设计像素网格，不出现 1–3px 的歪斜。
- 6px 内吸附到其它卡片与收纳面板的参考线：横向左/中/右，纵向上/中/下。
- 吸附命中时显示橙色参考线，松手消失。
- 目标：不同组件能落在同一条线上，也能拉成一致的宽高。

### FR-12 分组管理（P1，v0.4 新增）

- 分组标题上右键：重命名 / 上移 / 下移 / 在资源管理器中打开 / 删除。
- 重命名会同步重命名磁盘目录；顺序调整只改配置顺序，不动文件。
- 删除分组前必须把组内文件移回桌面，不允许连带删文件。

### FR-13 天气地点（P1，v0.4 新增）

- 天气卡双击，或托盘「天气地区…」打开搜索弹层。
- 支持中文省 / 市 / 区县（如「西湖区」「阳新县」），选中即生效并立即重拉。
- 卡片标题显示末级地名，悬停显示完整「省 · 市 · 区」。
- 搜索失败或离线时给出可读提示，不改变当前地点。

### FR-14 逐时预报跨天（P1，v0.5 新增）

- 「未来 6 小时」必须真的是接下来 6 个整点，不受当天剩余小时数限制。
- 跨到明天的格子有可见标记（标签上方小圆点），悬停提示「明天 08时」。
- 取数用接口返回的 `current.time` 对齐，不拿本机钟去猜时区。

### FR-15 打开收纳目录（P0，v0.5 新增）

- 面板右上角按钮与托盘菜单都要能打开收纳根目录。
- 必须走 `ShellExecuteW`：经由 `cmd /c start` 启动时，无控制台进程会派生出隐藏窗口。
- 失败不能静默：写 `launch.log`（含错误码），前端 toast 提示。

### FR-16 备忘录（P2）

- 两行文本，输入即存，重启保持。
- 不做富文本、不做提醒、不做多便签。

## 5. 非功能需求

| 类别  | 要求                                                            |
| --- | ------------------------------------------------------------- |
| 性能  | 常驻 CPU < 1%（采样 1 秒一次、光标轮询 30ms 只做 `GetCursorPos`）；内存 < 150 MB |
| 首屏  | 冷启动到可见 < 2 秒（不含抓屏，抓屏异步补）                                      |
| 缩放  | 设计坐标系 1920×1080，`ui = (屏宽/1920).clamp(1,2)`，4K 屏 2.0          |
| 可靠性 | 文件移动原子性：同盘 rename；跨盘复制成功后再删源，中间失败保留源                          |
| 隐私  | 无账号、无遥测；唯一外网请求是天气（只带经纬度）                                      |
| 可维护 | Rust 侧零 `unwrap` 崩溃点；无界面自检覆盖 8 项核心链路                          |
| 可诊断 | 截图自检可导出窗口/缩放/卡片矩形 JSON；事件监听失败会在页面上直接报错                        |

## 6. 交互约束

1. **不夺焦**：任何时候不得抢走前台窗口焦点，包括启动、截图、托盘操作。
2. **不挡手**：卡片之外的区域对鼠标完全透明，包括右键与框选。
3. **不惊喜**：任何会移动用户文件的操作，必须先给预览或二次确认。
4. **不覆盖**：任何写文件路径都必须先做重名检测。
5. **可反悔**：移动过的文件都能移回原位。
