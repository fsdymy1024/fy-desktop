# fy-desktop 需求文档

> 版本：v0.1.0 ｜ 最后更新：2026-11-15 ｜ 状态：已实现

## 1. 背景

Windows 桌面长期存在两个割裂的问题：

1. **信息要一层层点开才知道**。时间、天气、CPU、网速这些每天看几十次的信息，散落在任务栏托盘和各个应用里，没有一处「抬眼就能看到」的位置。
2. **图标越堆越多**。快捷方式、临时文件、下载的东西默认全落在桌面，最后桌面变成一片图标海，找东西靠肉眼扫描。

市面上 Fences 一类工具解决了收纳，但不做信息展示；Rainmeter 一类工具能展示，但配置成本高、视觉老旧。参考项目 [atrium-desktop](https://github.com/wynter-yaxley/atrium-desktop) 提供了方向：**液态玻璃质感的桌面层**，但它同时带了一整套任务栏 / 控制中心，超出本项目需要。

`fy-desktop` 只做两件事：**桌面小组件** + **桌面快捷方式收纳格子**。

## 2. 目标与非目标

### 2.1 目标

| 编号 | 目标 | 衡量方式 |
| --- | --- | --- |
| G1 | 抬眼可见：5 类常用信息常驻桌面 | 天气 / 时钟 / 日历 / 系统 / 网络 |
| G2 | 桌面变干净：快捷方式可按组收进格子 | 一键整理后桌面顶层只剩收纳目录 |
| G3 | 不打扰：不抢焦点、不挡桌面图标、不上任务栏 | 空区域鼠标事件穿透到桌面 |
| G4 | 可反悔：整理能还原 | `_manifest.json` + 一键还原 |
| G5 | 视觉统一：一套玻璃语言贯穿所有组件 | 设计令牌集中管理，换肤只改令牌 |

### 2.2 非目标（明确不做）

- ❌ **不做任务栏 / Dock**。参考项目的悬浮 Dock 属于独立模块，本项目不实现。
- ❌ **不做启动器 / 搜索**。不做全局搜索、应用启动、快捷指令。
- ❌ **不做窗口管理**（贴边、分屏、虚拟桌面）。
- ❌ **不做账号体系与云同步**。所有数据留在本机。
- ❌ **不做壁纸管理**。只使用系统壁纸，不接管、不修改。
- ❌ **不删除用户文件**。整理只移动，且可还原；删除能力不提供。

## 3. 目标用户与场景

**主用户**：Windows 10/11 上长时间面对电脑的重度用户——开发者、设计师、运营。特征是多窗口并行、桌面文件多、对视觉有要求。

**典型场景**

| 场景 | 触发 | 期望 |
| --- | --- | --- |
| 抬眼查信息 | 工作时随意一瞥 | 不用切窗口就知道现在几点、什么天气、机器热不热、网卡不卡 |
| 桌面被塞满 | 装完一堆软件、收了一堆文件 | 一键把散的图标收进「待整理」，需要时从格子点开 |
| 换壁纸想换观感 | 换了深色壁纸 | 玻璃自动跟随，或手动切「暮色」 |
| 临时挪位置 | 组件挡住了某块区域 | 进编辑模式拖走，松手即保存 |

## 4. 功能需求

优先级：P0 = 必须；P1 = 应该有；P2 = 可以有。

### FR-01 桌面小组件（P0）

| 组件 | 尺寸档 | 内容 | 数据来源 | 刷新 |
| --- | --- | --- | --- | --- |
| 天气 | 中 | 城市、当前温度、天气现象图标、最高/最低、未来 6 小时逐时 | Open-Meteo → wttr.in 回退 | 15 分钟 |
| 模拟时钟 | 小 | 表盘、刻度、12 数字、时分秒针 | 本地时间 | 1 秒 |
| 日历 | 小 | 星期、日、年月、ISO 周数 | 本地时间 | 30 秒 |
| 系统监视 | 中 | CPU / 内存 / 磁盘占用条 + CPU 走势 | `os` + `fs.statfs` | 1 秒 |
| 网络 | 中 | 实时上下行速率、延迟、链路类型/SSID、信号、本机 IP、吞吐走势 | `netstat -e` 差分 + TCP 握手 + `netsh wlan` | 2 秒 |
| 备忘录 | 中 | 3 条待办，可勾选 | 本地配置 | 手动 |

**验收**：所有组件在无人操作时持续刷新，数值与系统自带工具（任务管理器 / 网络设置）偏差在合理范围；任一数据源失败时组件显示占位态，不出现空白卡片或 `undefined`。

### FR-02 网络组件（P0，v0.1 新增）

- 显示当前**下行速率**为主数值，单位自动在 KB/s、MB/s、GB/s 间切换。
- 显示**上行速率**为次要数值。
- 显示**延迟**（毫秒），>60ms 变橙、>120ms 变红。
- 显示**链路**：Wi-Fi 显示 SSID + 信号百分比 + 四格信号条；有线显示「有线」并隐藏信号条。
- 显示**本机 IPv4**。
- 显示最近约 30 秒的**吞吐走势**（面积图）。
- 离线时状态点变红、文案变「离线」，延迟显示 `--`。

**性能约束**：单次采样不得阻塞渲染；不得每秒 spawn 子进程（`netstat` 采样周期 ≥ 2s，`netsh` 缓存 ≥ 12s）。

### FR-03 桌面快捷方式收纳（P0）

- 扫描用户桌面（`%USERPROFILE%\Desktop`）与公共桌面（`C:\Users\Public\Desktop`）的**顶层条目**。
- 按类型识别：快捷方式、链接、文件夹、文档、表格、演示、图片、压缩包、音视频、其他。
- 图标用「类型色块 + 首字/扩展名」生成，不解析 `.lnk` 目标（避免引入原生 COM 依赖）。
- 分组：开发工具 / 设计素材 / 常用文档 / 归档 + 系统内置「待整理」。
- 首次运行按名称关键词**自动归类一次**（只写归属，不动文件）。
- 每组可折叠；空组保留为可见的目标位。
- 单击打开、右键「打开 / 在资源管理器中显示 / 移入分组 / 移出分组」。

**验收**：扫描结果与资源管理器看到的顶层条目数量一致；`desktop.ini`、隐藏文件、本应用创建的收纳目录被排除。

### FR-04 一键整理与还原（P0）

- 「一键整理」先列出**将被移动的完整文件路径**，用户确认后才执行。
- 目标目录：`<桌面>/fy-desktop 收纳区/`，同名文件自动加序号后缀。
- **只移动文件，不移动文件夹，不删除任何东西**。
- 每次移动写入 `_manifest.json`（原名、原路径、时间）。
- 「还原」按 manifest 把文件放回原位，已存在同名文件时不覆盖，失败的条目保留在 manifest 里。

**验收**：整理 → 还原后，桌面条目与原状态一致；manifest 可读、可人工修正。

### FR-05 窗口行为（P0）

- 无边框、透明、无阴影、不显示在任务栏。
- 空区域**鼠标穿透**，桌面图标、右键菜单、框选照常可用。
- 鼠标进入组件区域时自动接管交互。
- 点击「显示桌面」（Win+D）导致的最小化立即恢复。
- 常驻系统托盘：显示/隐藏、编辑布局、材质、重新扫描、打开收纳目录、打开配置目录、开机自启、重置布局、退出。
- 单实例运行，重复启动时唤起已有实例。

### FR-06 布局与编辑（P1）

- 首次启动按屏幕工作区自动排布：左列贴左、收纳面板贴右，保证不超出屏幕。
- 编辑模式下可拖动任意组件，松手写入配置。
- 手动拖过之后不再自动重排；「重置布局」恢复自动排布。
- 分辨率变化时把组件夹回可视范围。
- 右键组件可「隐藏这个组件」。

### FR-07 材质与外观（P1）

- 三种材质：**跟随**（浅色半透明）、**暮色**（深色玻璃）、**原色**（近实底，组件带专属配色）。
- 材质从托盘或组件库切换，全局生效并持久化。
- 圆角 26px，细描边 + 内高光 + 细噪点构成玻璃质感。

### FR-08 备忘录（P2）

- 默认 3 条，勾选状态持久化。编辑文本能力留到 v0.2。

## 5. 非功能需求

| 类别 | 要求 | 现状 |
| --- | --- | --- |
| 性能 | 空闲 CPU 占用 < 2%；内存 < 200MB | CPU 采样 1s、网络 2s，均为轻量 IO |
| 启动 | 冷启动到可用 < 2s | 渲染层无框架、无打包，直接 ESM |
| 资源 | 不引入原生模块，`npm install` 后即可运行 | 仅依赖 Electron |
| 安全 | 渲染层 `contextIsolation`、无 `nodeIntegration`、IPC 白名单、本地 CSP | 已实现 |
| 隐私 | 不采集、不上报；仅天气请求携带经纬度（可在配置里改） | 无遥测 |
| 数据安全 | 不删除用户文件；整理前二次确认；移动有 manifest | 已实现 |
| 兼容 | Windows 10 1809+ / Windows 11；多分辨率与高 DPI | 自动缩放 1.0–1.75 |
| 可维护 | 主进程 / 预加载 / 渲染层三层分离，服务层单一职责 | 见设计文档 |
| 可观测 | 冒烟测试 + 截图自检可在无人值守下验证 | `npm run smoke` / `npm run shot` |

## 6. 交互约束

- **不抢焦点**：启动用 `showInactive`，只有用户主动点击组件才获得焦点。
- **不遮挡**：组件之间默认留 16px 间距，避免视觉粘连。
- **可撤销**：所有会改动用户数据的操作必须二次确认，且提供回退路径。
- **不打断**：不使用系统通知弹窗；反馈统一走底部 Toast。
